What is code, anyway?

Code is just a list of exact instructions for a computer — like a recipe for a robot. The computer does exactly what you tell it, in exactly the order you tell it. Nothing more, nothing less!

Big idea: A computer has no imagination. If you forget a step, it won't guess what you meant — it'll just get stuck (or do something silly).

Watch what happens when we "run" the instructions for making a peanut butter sandwich:

1🍞 Get bread
2🥜 Add peanut butter
3🍞 Add second slice
4😋 Eat!

That's it — that's code! Now let's write real instructions for Rosie the rocket.

Sequences: order matters

A sequence is a set of steps that happen one after another, in order. Help Rosie fly straight up, then turn and fly to the star ⭐ — using the fewest, clearest commands you can.

Try it: Click commands to build your program, then hit Run. Get the order wrong and Rosie will fly off course!
🚀

🔁

Loops: don't repeat yourself

Rosie needs to fly a long way this time. You *could* click "Forward" six times... or you could use a loop to repeat a command automatically!

Big idea: A loop says "do this again" so you don't have to write (or click!) the same instruction over and over.
🚀

❓

If / Else: making decisions

Sometimes code needs to make a choice. This "smart" block checks the sky ahead: if there's open space, Rosie flies forward — else, she turns. Click it a few times and watch her think for herself!

Under the hood: IF space ahead → fly forward, ELSE → turn left
